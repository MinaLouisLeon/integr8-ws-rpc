## Review focus

- A required per-call context on one child must survive alongside a differently typed sibling.
- Malformed/getter-valued configuration must fail before any listener registration.
- Reentrant group close and listener failures must not skip another child's cleanup.
- Return/abort must settle pending iteration even if Blob or observer work never settles.
- Chunk bytes/progress must never be described as wire size, transfer completion or acknowledgement.

## Execution record

Checkmarks mean source written except the explicitly executed lint/typecheck step. Tests were
written before production modules, but no test red/green run is claimed: AGENTS reserves runtime
tests/build/packaging/device checks for the developer. All new code and examples typecheck; final
plain lint and typecheck results are in SPEC Progress/handoff. No dependencies/installs/agents,
commits, pushes or publication.

Ruling: share one sanitized connect promise per child while delegating the actual attempt to the
original handle; this preserves concurrent group calls and prevents foreign async lifecycle errors
from leaking raw causes. It introduces no retry/routing engine or cross-child promise sharing.

Ruling: assign cleanup promises before invoking children, and start child close synchronously before
returning the group promise. This prevents reentrant duplicate cleanup and closes original clients
without a microtask window for new calls. Await every cleanup before final aggregate notification.

Ruling: serialize requested iterator pulls without storing produced chunks; caller-retained input,
requests/output and non-interruptible platform reads cannot be a whole-transfer memory guarantee.
Copy bounded native views rather than virtual subarray results to avoid unbounded overridden copies.

Ruling: local EOF commits before its completion callback. Already-observed progress cannot be
retracted; callback failures propagate, while abort/return can release an uncooperative EOF observer
without undoing local completion. Pre-EOF abort remains CANCELLED and suppresses later completion.

Source review additionally corrected stale notifications during reentrant group close, reopening a
named closed child, snapshot accessor re-reads, unsafe config causes and late read/callback results.
Only a bounded validated-key projection uses a mapped-record assertion; there is no any or
client/router inference cast. Existing size budgets were retained, not measured or weakened.
