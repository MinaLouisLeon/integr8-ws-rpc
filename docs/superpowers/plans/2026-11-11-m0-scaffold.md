- Public initial subpaths: package root, `/client`, `/server`, `/fastify`.
- No Node runtime imports in root/client; no source-containing maps; publish only dist.
- No installs or implementation checks by the agent; developer records all execution evidence.
- No manifest dependencies before approval, no public/wire/default changes without review.
- M0 only; M1–M6 remain separate milestones.

## Review focus

- oRPC v1/v2 API confusion: fixture must compile against exact approved pins.
- Upstream iterator buffering: actual peer boundary must enforce item AND byte bounds.
- Concurrent hello/app calls: no principal context before successful authentication.
- Import isolation: root/client must load without Node server imports or opening sockets.
- Disposal and raw upstream errors: listeners must be removable and diagnostics safe.
